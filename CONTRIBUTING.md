# Contributing to Yui in the browser

Thanks for helping. Yui is open source and built in public: every change that ships goes on [yuigui.com/progress](https://www.yuigui.com/progress).

- **Work from a card.** The backlog is [yuigui.com/contribute](https://www.yuigui.com/contribute), and its JSON is https://www.yuigui.com/contribute/backlog.json. Pick one open card for this repo, and title the pull request `[KEY] <card title>`.
- **No card for what you want?** Write a short spec in the hub repo: copy [docs/specs/TEMPLATE.md](https://github.com/postscarcityai/yuigui/blob/main/docs/specs/TEMPLATE.md) to `docs/specs/<short-name>.md` there and open a pull request. A person reads every one, and a good fit becomes a card.
- **One card per pull request.** Found something else? Say so in the pull request, and do not fix it in the same one.
- **Tests pass, output in the pull request.** Screenshots in light and dark when anything on screen changes.
- **Plain words** in anything a person sees. No em dashes, no developer tooling on screen.
- **No new dependency** without a note in the pull request saying why.
- **Security problem?** Please read [SECURITY.md](SECURITY.md) first and do not open a public issue.

By opening a pull request you agree your work is licensed under Apache-2.0, like the rest of the repo. Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
